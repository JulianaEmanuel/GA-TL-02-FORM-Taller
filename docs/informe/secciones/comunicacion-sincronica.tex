\paragraph{Comunicación sincrónica y fallos.}
El Gateway y los servicios usan REST sobre HTTPS, mecanismo principal de CLAB
según su ADR-002. Reservas consulta a Laboratorios las condiciones operativas,
y Laboratorios consulta a Identidad al asignar encargados. Antes de confirmar,
cancelar o bloquear, se verifica con Identidad que la sesión siga vigente; si
no puede verificarse, la operación no se ejecuta (RNF-03). Cada llamada tiene
un tiempo de espera acotado (RNF-01); si Laboratorios no responde, la reserva
queda sin confirmar.
