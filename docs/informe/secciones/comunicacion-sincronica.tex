\paragraph{Comunicación sincrónica y fallos.}
Los borradores proponen REST sobre HTTPS entre Gateway y servicios, y para consultas
internas: Reservas consulta condiciones operativas a Laboratorios, y
Laboratorios consulta Identidad al asignar encargados. REST permite una
respuesta inmediata y conserva el estilo de API de CLAB. Si Laboratorios
no responde, la reserva queda sin confirmar; si falla Identidad, no se ejecuta
la asignación. Falta vincular esta elección a los RNF concretos del PFC.
