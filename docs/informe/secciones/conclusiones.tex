\section{Cierre}
La propuesta divide CLAB en cuatro servicios con bases exclusivas y una
entrada única por el API Gateway. Usa REST para decisiones inmediatas y
RabbitMQ para propagar cambios. Los contratos y los RNF se validarán con
pruebas en la PE-U2.
