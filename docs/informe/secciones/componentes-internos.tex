\paragraph{Componentes.}
El C4 de nivel 3 muestra los componentes que gestionan reservas, recursos
físicos, accesos y datos académicos, y avisos y auditoría. Reservas y Agenda
consulta las condiciones operativas de Laboratorios y Recursos antes de
confirmar una franja. Cada microservicio accede a su propia base de datos.
