\paragraph{API Gateway.}
Entrada única para clientes web y móvil. Valida la firma y vigencia del JWT
emitido por Identidad y Académico, enruta cada solicitud al servicio
propietario y limita las solicitudes por usuario~\cite{haindl2024interservice}.
Responde 401 ante un token inválido, 429 al superar el límite y 503 si el
servicio destino no responde.
