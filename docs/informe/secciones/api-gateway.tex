\paragraph{API Gateway.}
Se propone una entrada única para clientes web y móvil, con enrutamiento,
autenticación y limitación de solicitudes. El Gateway dirige cada operación
al servicio propietario. Quedan por concretar el mecanismo de autenticación,
los límites y el tratamiento de errores con los responsables de los servicios.
