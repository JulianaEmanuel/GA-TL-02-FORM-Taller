# Decisiones de arquitectura tras la revisión

Crear un nuevo ADR cuando una observación de la revisión docente cambie una decisión arquitectónica. El responsable de la decisión lo redacta y los integrantes afectados revisan su coherencia con el C4.

Usar `ADR-NNN-titulo.md` con el siguiente número libre del repositorio del PFC; evitar colisiones al integrar este taller. Incluir fecha, estado, observación que lo origina, contexto, alternativas, decisión, justificación según RNF y consecuencias, incluidos fallos y consistencia cuando corresponda.

Enlazar el ADR desde la fila correspondiente de `../informe/tablas/retroalimentacion.tex` y actualizar el diagrama. No crear una decisión ficticia antes de la revisión ni sobrescribir un ADR anterior para ocultar el cambio.
